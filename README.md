# Weighted Allocation Probability Adjusted Thompson Sampling (WAPTS) work codebase

This is the renewed codebase for the WAPTS policy. It currently contains six policy: Uniform Random (UR), Sub-Sampled Greedy Method (SS-Greedy), Thompson Sampling (TS), Epsilon-Greedy Thompson Sampling (epsilon-TS), WAPTS, Information Relaxation Thompson Sampling (IRS-FH_TS). It also created all the plots.

We will use this code base to provide a base for simulations that we run in WAPTS work.
